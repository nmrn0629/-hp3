# 年末調整 控除額チェッカー（所内用）

条件を選択・入力していくと、所得税の年末調整で適用される所得控除とその金額を一覧表示する、事務所内用の確認ツールです。
ホームページには掲載せず、単独で使います。

## 使い方

1. `nencho-checker/index.html` をブラウザで開く（ダブルクリックでOK。サーバー不要・オフラインでも動作）。
2. 画面の案内に沿って入力する。
   - ① ご本人：対象年分、給与収入（額面）、障害者区分、配偶者の有無・婚姻状況、勤労学生
   - ② 配偶者：生年月日、収入、障害者区分（①で「配偶者がいる」を選んだ場合のみ）
   - ③ 扶養親族：人数分を追加。続柄・生年月日・収入・同居・障害者区分
   - ④ 保険料・掛金：社会保険料、iDeCo等、生命保険料（新旧）、地震保険料、住宅ローン控除額
   - ⑤ 結果：所得控除の一覧と合計、所得金額の計算過程、参考の所得税額概算
   - 画面上部のタブで「家族一人ひとりの判定」に切り替えると、1人ずつの区分・控除額を確認できます（下記）。
3. 「印刷・PDF保存」でそのまま印刷／PDF化できます。
4. 入力内容はブラウザのメモリ上だけで計算し、どこにも送信・保存しません。ページを閉じると消えます。

## 画面構成（2つのタブ）

### ① 世帯の控除額チェッカー
本人→配偶者→扶養親族→保険料の順に入力し、世帯全体で受けられる所得控除とその合計、所得税額の概算を表示します（上記「使い方」）。

### ② 家族一人ひとりの判定
配偶者やお子さん、ご両親など **1人分** を入力すると、その場で次を判定します。

- **該当する区分**：配偶者なら「同一生計配偶者／控除対象配偶者／老人控除対象配偶者／源泉控除対象配偶者／配偶者特別控除の対象」、親族なら「扶養親族／年少扶養親族（16歳未満）／控除対象扶養親族／特定扶養親族／老人扶養親族／同居老親等／特定親族／源泉控除対象親族」。該当しない場合は理由を表示。
- **障害者区分**：手帳の種類と等級から「一般の障害者／特別障害者／同居特別障害者」を判定（身体1・2級＝特別、3〜6級＝一般、精神1級＝特別、2・3級＝一般、療育 重度＝特別、戦傷病者 特別項症〜第3項症＝特別、被爆者・寝たきり・成年被後見人＝特別、市町村長等の認定は認定内容による）。
- **控除額**：配偶者控除／配偶者特別控除／扶養控除／特定親族特別控除／障害者控除のそれぞれについて金額と根拠、**記載する申告書と欄**（扶養控除等申告書 A・B・C欄／住民税に関する事項、配偶者控除等申告書、特定親族特別控除申告書）。
- **関連する注意点**：所得金額調整控除の要件該当、生命保険料控除の特例（23歳未満）、住民税欄への記載など。
- 事業専従者、他の人の扶養に入っている場合の除外にも対応。

## 対応年分と法令の根拠

令和8年分（既定）と令和7年分に対応しています。令和8年分は、**令和8年度税制改正（令和8年12月1日施行・令和8年分以後の所得税に適用）** を反映しており、国税庁HPの次の資料と照合済みです（2026年10月8日時点）。

- 「令和8年分 年末調整のしかた」Ⅰ 昨年と比べて変わった点 — https://www.nta.go.jp/publication/pamph/gensen/nencho2026/pdf/102.pdf
- 「令和8年度税制改正（所得税の基礎控除の引上げ等関係）Q&A」 — https://www.nta.go.jp/users/gensen/2026kiso/pdf/0026005-024.pdf
- タックスアンサー No.1199（基礎控除）、No.1410（給与所得控除）、No.1180（扶養控除）、No.1191／1195（配偶者控除・配偶者特別控除）、No.1177（特定親族特別控除）、No.1160（障害者控除）、No.1170／1171（寡婦控除・ひとり親控除）、No.1175（勤労学生控除）、No.1140（生命保険料控除）、No.1145（地震保険料控除）、No.1411（所得金額調整控除）、No.2260（所得税の税率）

### 令和8年分で変わった主な点（実装済み）

| 項目 | 令和7年分 | 令和8年分 |
|---|---|---|
| 基礎控除 | 95／88／68／63／58万円（所得段階別） | 合計所得489万円以下 **104万円**、489万超655万以下 **67万円**、655万超2,350万以下 **62万円**（2,350万超は従来どおり） |
| 給与所得控除の最低保障 | 65万円（収入190万円まで） | **74万円**（収入220万円まで）。収入69.1万〜220万円未満は特例の定額計算 |
| 扶養親族・同一生計配偶者・ひとり親の子の所得要件 | 58万円以下（給与123万円以下） | **62万円以下**（給与136万円以下） |
| 特定親族特別控除の対象 | 所得58万超123万以下 | **62万超**123万以下（給与136万超197万以下） |
| 配偶者特別控除の対象 | 所得58万超133万以下 | **62万超**133万以下 |
| 勤労学生控除 | 合計所得85万円以下 | **89万円以下**（給与163万円以下） |
| 生命保険料控除（23歳未満の扶養親族あり） | 特例なし | 一般・新契約の限度額 **6万円**（新旧合算も6万円、合計12万円は不変） |
| ひとり親控除 | 35万円 | 35万円（38万円への引上げは令和9年分以後） |

## 判定している控除

| 控除 | 判定に使う条件 |
|---|---|
| 基礎控除 | 本人の合計所得金額 |
| 配偶者控除／配偶者特別控除 | 本人所得・配偶者所得・配偶者の年齢（70歳以上） |
| 扶養控除（一般・特定・老人・同居老親等） | 扶養親族の年齢（12月31日時点）・所得・続柄・同居 |
| 特定親族特別控除 | 19歳以上23歳未満、所得が扶養親族の所得要件超123万円以下 |
| 障害者控除（本人・配偶者・扶養親族） | 一般／特別／同居特別 |
| 寡婦控除／ひとり親控除 | 婚姻状況、事実婚、子の有無、本人所得500万円以下 |
| 勤労学生控除 | 合計所得金額の上限かつ給与以外10万円以下 |
| 社会保険料控除・小規模企業共済等掛金控除 | 入力額の全額 |
| 生命保険料控除 | 新旧契約の算式、合計上限12万円、23歳未満の扶養親族がいる場合の特例 |
| 地震保険料控除 | 地震保険料・旧長期損害保険料 |
| 所得金額調整控除（子ども等） | 給与収入850万円超かつ23歳未満の扶養親族／特別障害者 |

あわせて、給与所得控除・給与所得・合計所得金額の計算と、参考として所得税額の概算（復興特別所得税込、住宅ローン控除反映）を表示します。

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の枠 |
| `nencho.css` | スタイル |

## 毎年の更新方法

税制改正への対応は原則 `nencho-rules.js` だけで完結します。

1. `RULES` に新しい年分のエントリを追加する（既存年をコピーし、改正点だけ書き換える）。
   - 例：令和9年分は基礎控除・給与所得控除・所得要件は令和8年分と同じ見込みですが、ひとり親控除が38万円に、復興特別所得税率が1.1%（＋防衛特別所得税）に変わる予定です。
   - 年分限定の特例（令和8・9年分の生命保険料控除 6万円など）は該当年だけに設定する。
   - 給与所得の計算構造が変わる場合は `salaryDeduction.variant` を追加して `salaryIncome()` に分岐を足す。
2. 年分セレクトは `RULES` のキーから自動生成されるので、UI側の修正は不要。
3. 年齢区分の判定日はその年の12月31日で自動計算される（1月1日生まれは前日に加齢する扱いを含む）。

## 計算ロジックの確認

`nencho-rules.js` は Node.js でもそのまま読み込めます。国税庁の控除額表を期待値にした照合テストを同梱しているので、ルール表を更新したら実行してください。

```bash
node nencho-checker/tests/rules.test.js
```

## 注意事項

- 所得税の年末調整における確認用の概算です。最終的な判定は各申告書・証明書に基づいて行ってください。
- 国外居住親族、青色事業専従者・事業専従者、他の人の扶養に入っている親族などの特殊ケースは考慮していません。
- 医療費控除・寄附金控除・雑損控除・住宅ローン控除1年目は年末調整の対象外です（確定申告）。
